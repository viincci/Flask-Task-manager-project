# Flask-Task-manager-project
## Description
A task management web application built with Flask, allowing users to create, edit, and delete tasks, with features such as user authentication and authorization.
## Key Features
- User registration and login
- Task creation, editing, and deletion
- User authentication and authorization
- Flash messages for user feedback
## Tech Stack
- Flask
- SQLAlchemy
- Bootstrap
- HTML/CSS
## Installation
1. Clone the repository: `git clone https://github.com/your-username/Flask-Task-manager-project.git`
2. Create a virtual environment: `python -m venv venv`
3. Activate the virtual environment: `source venv/bin/activate`
4. Install dependencies: `pip install -r requirements.txt`
## Usage
1. Set environment variables: `export SECRET_KEY=your-secret-key` and `export DATABASE_URL=your-database-url`
2. Run the application: `python app.py`
3. Open a web browser and navigate to `http://localhost:5000`
## Environment Variables
- `SECRET_KEY`: a secret key for the Flask application
- `DATABASE_URL`: the URL of the database to use
